# Сравнение Git и SVN

## Почему ветвление в Git дешёвое?
Ветка Git является указателем на коммит и создаётся локально. В SVN ветки представлены копиями каталогов на сервере. SVN поддерживает дешёвое копирование, поэтому утверждение о полном дублировании файлов при каждом создании ветки неточно. Основное различие касается модели работы с историей и ветками.

## Можно ли сделать коммит в SVN без интернета?
Нужен доступ к серверу SVN. При отсутствии соединения с удалённым сервером коммит невозможен, но редактировать локальные файлы можно. Если сервер находится локально или доступен по локальной сети, интернет не требуется. В Git коммиты создаются в локальном репозитории без доступа к серверу.

## Когда SVN может быть предпочтительнее?
При поддержке существующих SVN-проектов, необходимости централизованного доступа по каталогам и рабочих процессах, использующих блокировку отдельных файлов.
