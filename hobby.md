# Мой пет-проект

Идея: консольное приложение для учёта личных расходов.

Стек: Python, SQLite.

Цель: освоить работу с базой данных, тестирование и запуск приложения в Docker.

## Основные функции
- Добавление расходов с датой, суммой и категорией.
- Просмотр расходов за месяц.
- Подсчёт расходов по категориям.
