# Подготовка к контрольной

## Merge и rebase
Merge объединяет истории веток. Rebase переносит мои коммиты на новую базу. Rebase удобен для личной локальной ветки, merge — для объединения общей истории.

## Rebase публичной ветки
Rebase изменяет хеши коммитов. Коллегам, использующим старую историю, придётся согласовывать свои ветки с новой историей.

## Multi-remote
Несколько remote позволяют работать с основным репозиторием, зеркалом и оригиналом при использовании форка.
